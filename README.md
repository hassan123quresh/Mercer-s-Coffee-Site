# Luxury Coffeehouse Website

A premium, modern web application for a luxury coffeehouse, featuring a minimalist design, smooth inertia scrolling, and an integrated booking system.

## ✨ Features
- **Premium Aesthetics**: Curated color palette and modern typography (Inter & Cormorant Garamond).
- **Smooth Scrolling**: Physics-based inertia scrolling using the Lenis library.
- **Dynamic Menu**: Categorized menu with interactive product displays.
- **Booking System**: Global booking modal with WhatsApp integration for reservations.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.

## 🛠️ Tech Stack
- **Core**: React, TypeScript, Vite
- **Styling**: Vanilla CSS with modern layout techniques (Grid, Flexbox)
- **Animations**: CSS Transitions, Framer Motion (optional/where applicable)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/luxury-coffeehouse-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd luxury-coffeehouse-website
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development
Start the local development server:
```bash
npm run dev
```

### Production
Build the project for production:
```bash
npm run build
```
